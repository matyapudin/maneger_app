# maneger_app

タスク管理・メール管理（Gmail）・大学の課題（AIMS）をまとめて管理する Web アプリです。パソコンで使う想定です。

1 画面にすべてをまとめています。

- 上：タスク（追加・完了）
- 左上：メール（未読が目立つ。行にマウスを乗せると「非表示」ボタン）
- 左下：カレンダー（1 週間。Google カレンダーの予定・課題の締め切り・タスク）
- 右：AIMS の課題（授業ごと。提出不要の課題は自動で見分ける）

開いたときにデータが 10 分以上古ければ、AIMS・Gmail・Google カレンダーから自動で取り込み直します。

- フレームワーク: Next.js（TypeScript, App Router）
- データベース: SQLite（Node.js に内蔵の `node:sqlite`）
- 必要なもの: Node.js 22.13 以上（https://nodejs.org/ja の LTS 版で OK）

## 動かし方（Windows）

1. アプリのフォルダーにある **`start.bat` をダブルクリック** します。
   - 初回だけ、部品の準備と組み立てに数分かかります。
   - 起動するとブラウザで http://localhost:3000 が開きます。
   - デスクトップに「マネージャー」のショートカットができるので、次からはそれをダブルクリックするだけです。
2. アプリを止めるときは、タスクバーにある「マネージャー（このウィンドウを閉じるとアプリが止まります）」のウィンドウを閉じます。

### アプリを新しくするとき

新しい ZIP をダウンロードして展開し、その中の `start.bat` をダブルクリックします。
デスクトップのショートカットは自動で新しいフォルダーに向き直ります。古いフォルダーは消して大丈夫です。

### データの保存場所

ログイン情報やタスクは、アプリのフォルダーとは別の場所に保存します。アプリを新しくしても消えません。

- Windows: `%APPDATA%\maneger_app\app.db`
- そのほか: `~/.maneger_app/app.db`

### Windows 以外・開発するとき

```bash
npm ci
npm run dev
```

## AIMS（大学の課題）との連携

AIMS は Moodle で動いているので、Moodle の Web サービス API で課題を取り込みます。

1. 「設定」画面で、AIMS にログインするときの **ユーザー名とパスワード** を入れて「AIMS に接続」を押します。
   公式の Moodle アプリと同じ仕組みで、AIMS から「鍵（トークン）」を受け取ります。
   **パスワードは保存しません。** 保存するのは鍵だけです。一度つなげば、次からは入力不要です。
2. ホーム画面を開くと、自動で課題を取り込みます（右上の ↻ でいつでも取り込み直せます）。

## Google（Gmail・カレンダー）との連携

Google の OAuth（ログインして「このアプリが Gmail を読んでよい」と許可する仕組み）を使います。
アプリが受け取るのは **読み取り専用** の権限（`gmail.readonly`）だけで、メールの送信や削除はできません。
費用はかかりません（支払い情報の登録も不要です）。

### 1. Google Cloud で準備する（最初の 1 回だけ）

1. https://console.cloud.google.com/ を開き、新しいプロジェクトを作ります。
2. 「API とサービス」→「ライブラリ」で次の 2 つを探して、それぞれ「有効にする」を押します。
   - **Gmail API**
   - **Google Calendar API**
3. 「Google Auth Platform」（または「OAuth 同意画面」）を開いて設定します。
   - 対象：**外部**
4. 「クライアント」（または「認証情報」→「OAuth クライアント ID を作成」）で次のように作ります。
   - アプリケーションの種類：**ウェブ アプリケーション**
   - 承認済みのリダイレクト URI：`http://localhost:3000/api/auth/google/callback`
5. 表示された **クライアント ID** と **クライアント シークレット** を、アプリの「設定」画面に入れて「保存」を押します。

### 2. 7 日で切れないようにする

Google 側のアプリが「テスト中」のままだと、約 7 日で接続が切れます。次の設定で防げます。

1. Google Cloud の「Google Auth Platform」→「対象」（Audience）を開きます。
2. 「公開ステータス」の **「アプリを公開」** を押して「本番環境」にします。
   - Google の審査（確認）は受けなくて大丈夫です。自分だけで使う場合、審査なしでも使えます。
   - その代わり、接続するときに「このアプリは Google で確認されていません」と表示されます。
     「詳細」→「（アプリ名）に移動」で進めてください（自分で作ったアプリなので問題ありません）。
3. 公開したあと、アプリの「設定」画面で一度「接続を解除」して、もう一度「Gmail に接続」を押します。

### 3. アプリから接続する

1. 「設定」画面の「Gmail に接続」を押します。
2. Google の画面で自分のアカウントを選び、許可します。
3. ホーム画面を開くと、受信トレイの最新 30 件を自動で取り込みます（右上の ↻ でいつでも取り込み直せます）。

「接続を解除」を押すと、保存したログイン情報を消し、Google 側の許可も取り消します。

## Google カレンダー

- 表示中のカレンダーの予定（前後 2 週間〜2 か月分）を、ホームのカレンダー欄に表示します。
- AIMS の課題の締め切りを、アプリが作る専用のカレンダー「**Manager 課題の締め切り**」に書き込みます。
  - 締め切りの 30 分前から締め切りまでの予定として入ります。
  - 締め切りが変わると更新し、提出済み・提出不要にした課題は自動で消えます。
  - アプリが書き込めるのはこの専用カレンダーだけで、ほかのカレンダーの予定は変更できません。
  - 「設定」で書き込みをオフにすると、書き込んだ締め切りをすべて消します。
- Notion カレンダーで Google アカウントを表示していれば、そちらにも同じ予定が出ます。

### すでに Gmail をつないでいる場合

Gmail だけの許可でつないでいた場合は、カレンダーの許可を追加します。

1. Google Cloud で **Google Calendar API** を有効にします（上の手順 2）。
2. アプリの「設定」で「**カレンダーの許可を追加**」を押し、Google の画面で許可します。

## メールからのタスクの提案

日付が書いてあるメールに、「📅 11/20（金）17:00 締め切り ＋タスク ×」のような提案を表示します。
**勝手には追加しません。** 「＋タスク」を押したときだけ、メールの件名をタイトルにしてタスクに追加します（元のメールへのリンク ↗ 付き）。

- AI は使いません。件名と本文から決まった形の日付を探します（無料・メールは外部に送りません）。
  - 「2026年11月20日」「11月20日」「11/20」「明日」「明後日」と、続く時刻（「17:00」「17時」「午後5時半」など）
  - 日付の近くの言葉で「締め切り」（〆切・までに・提出・期限 など）か「予定」（開催・日時・集合・から など）かを見分けます
- 今日より前の日付と、リンク（URL）の中の数字は提案しません。
- 「×」で消した提案や、追加した提案は、取り込み直しても出てきません。
- メールの本文は日付を探すためだけに読み、保存しません。

日付の見つけ方のテストは `npm test` で実行できます。

## 集中タイマーと作業用 BGM

画面右上にあります。

### 集中タイマー
- 「▶」で開始、「❚❚」で一時停止、「↺」でリセット。
- 「作業」「休憩」を押すと切り替わります。時間の長さは 25/5 分・50/10 分・15/3 分から選べます。
- 時間になると音が鳴り、自動で次（作業→休憩、休憩→作業）に切り替わります。初めて開始するときに通知の許可を聞かれるので、許可するとデスクトップにも通知が出ます。
- 動いている間は、ブラウザのタブに残り時間が出ます。ページを開き直しても続きから動きます。
- 「今日 ○ 回」は、今日終えた作業の回数です。

### 作業用 BGM（YouTube）
- 「♪ BGM」を押すと、右下に小さなプレーヤーが開いて再生が始まります。「閉じる（停止）」で止まります。
  - YouTube の決まりで、埋め込みのプレーヤーは画面に見える状態（200×200 ピクセル以上）で表示する必要があるため、音だけを裏で流すことはできません。
- 最初から 2 つのライブ配信（lofi hip hop radio / synthwave radio）を入れてあります。
  - 配信が終わっていて流れないときは、「＋」から好きな YouTube の URL（動画・ライブ・再生リスト）を追加してください。
- 追加したステーションは、このパソコンのブラウザに保存されます。
